Gesture-Based Emergency Communication System

An Arduino-based prototype exploring how hand gestures can be used to communicate basic emergency messages.

Explore Project View Source Code

About the Project

Suraksha Glove is a gesture-based emergency communication prototype designed to explore an alternative way of sending simple messages when conventional verbal communication is difficult.

The prototype uses flex sensors and an inertial measurement unit to capture hand movement and gestures. An Arduino UNO processes the sensor inputs and supports communication of predefined messages.

How It Works

01. Gesture Detection

Flex sensors detect finger bending, while the MPU6050 provides motion-related data.

02. Processing

Arduino UNO reads the sensor values and processes the gesture inputs.

03. Message Output

Predefined messages such as HELP, YES and NO can be communicated through the prototype's output system.

Hardware & Technologies

Arduino UNO Flex Sensors MPU6050 16×2 LCD HC-05 Bluetooth Embedded C/C++

Project Objective

The objective is to explore a low-cost, gesture-based communication approach using embedded electronics and sensor integration.

This is an academic prototype, not a certified emergency or medical communication device.
